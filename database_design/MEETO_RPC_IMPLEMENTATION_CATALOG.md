# Meeto — danh mục RPC/API phải lập trình sau nhiệm vụ04

Tất cả operation bên dưới **chưa có production function body** trong hai SQL thiết kế.21 helper authorization đang có không phải21 mutation RPC. Các SQL kiểm thử local chỉ dùng role/schemas tổng hợp, không tạo các API nghiệp vụ này.

- API Supabase Auth chuẩn (signup,verify,email reset,OTP,refresh,signout) dùng Auth endpoints, không tự tạo SQL function nhận plaintext password.
- Mutation PostgreSQL là transaction đơn server; Edge chỉ điều phối network/worker, không ghép nhiều Android request thành transaction.
- Common errors:401 no identity;403 deny;404 unavailable (không tách exists/notauthorized);409 state/version/idempotency conflict;410 expired;422 validation;429 quota. SQLSTATE23505 xử lý theo đúng unique key, không mặc định mọi23505 là retry success;40001/40P01 bounded retry cùngrequestUUID.
- SECURITY DEFINER implementation private/actor-bound, search_path='', schema-qualified; explicit execute grant theo migration owner. Public wrappers invoker hoặc Edge được verify, không nhận actor_id tùy ý. Default EXECUTE toàn cục của app migration owner đã được siết trong schema draft.
- Các tên nhóm dùng dấu / là các entry point riêng hoặc action enum server có validate đầy đủ, không một “generic update any table” RPC.

## Lock và scope bắt buộc
- Pair canonical UUID trước resource parent khi có quan hệ2 người; group lock trước group post/member mutation; conversation trước message/member/read; post trước comment/reaction; nhiều ID theo thứ tự tăng. Không dùng session advisory lock với pooler.
- Lập account-suspension/deletion workflow trước bật Group Admin: membership admin cuối và “admin có thể hoạt động” là hai invariant khác nhau. Không tự bỏ suspension để giữ nhóm. Phải duyệt autoarchive/read-only hoặc transfer qua staff workflow; kiểm tra quyền đồng thời dưới cùng parent locks.
- Những route read cho feed/search/inbox phải dùng invoker/RLS hoặc kiểm tra ACL/projection tương đương. Definer JOIN profiles/private tables không được bypass field privacy rồi trả tất cả columns.
- Maintenance/import/cascade có thể bypass các RPC writer; worker dùng cùng invariant/reconciliation và kiểm thử riêng, không trông chờ counter CHECK>=0 giữ số liệu chính xác.

## Test cho từng implementation
Mỗi dòng catalog có tests allow/deny (actor/other/blocked/locked), expected constraint errors, retry lost ACK và concurrent two-connections nếu có multi-row write. Local audit99 assertion+3 race chỉ xác minh constraints/read-policies/patterns; không làm các API trên trở thành completed.
