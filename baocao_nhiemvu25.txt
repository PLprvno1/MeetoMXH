# MEETO — Task 25: Advanced Messenger

## Reused foundations

- Existing reply RPC validates that the source message is visible and belongs to the same conversation; existing reply preview, recall, delete-for-me, delivery/read receipts and message pagination remain in use.
- Existing private Realtime invalidation, event outbox, retry/idempotency, image/video upload and private media authorization remain in use.
- Existing `search_messages` RPC is retained. Migration 032 adds edit, text-forward and authorized inbox search RPCs.

## Changes

- Added migration `20261103001400_advanced_messenger.sql`: a forwarded marker, versioned server-side text edits with a 15-minute server timestamp window, idempotent text forwarding between authorized conversations, and search over conversations visible to the current member.
- Added a Material bottom sheet for message actions, edit composer state, text-forward target selection with preview, conversation search, and attachment preview before upload.
- Reply previews now carry the authorized source sequence, load older history until the source is found, and show a placeholder when it is no longer available.
- Extended chat attachment UI to select photos and MP4 video. Existing private media pipeline and video playback are used. Media references stay `asset://` IDs; storage paths and signed URLs are not exposed.
- Added focused model tests for edited/forwarded/recalled message state.
